# Sunny 金毛一周测试素材

全部年龄、性格、行为、时长与背景都是为测试编造的数据，不是用户照片中真实犬只的生活史。用户照片只作为头像，不充当任何行为记录的证据，也不提交到 GitHub。

- 宠物：Sunny (Test Golden Retriever)，Golden Retriever，3岁；虚构补充设定为雌性、28 kg。
- 期间：2026-10-09 至 2026-10-15，Asia/Singapore。
- 45条可在 Story 查看并打开的文字观察、2条生活事件、7份结构化每日汇总。
- 每日覆盖晨间散步、早餐、午后休息、室内互动、傍晚散步、晚餐和晚间安定。10月11日午后休息缺失，10月15日只到16:30。
- 使用 `hasDemoMoments:false`，不混入原型 Luna 的预设片段；不预写“已确认 baseline”。

|---|---:|---:|---|
| 10-09 | 62 | 88 | 常规参考日 |
| 10-10 | 64 | 95 | 常规参考日 |
| 10-11 | 60 | 缺失 | 保留散步数据，休息不计0 |
| 10-12 | 63 | 90 | 常规参考日 |

以10月9–13日为明确测试参考段：日散步中位数63分钟，午后休息中位数91分钟（有效4日）。这只是用于验证程序的样本期望值，不是经过验证的健康标准。雨天、访客和不完整日用于后续情境比较测试。

`testData.dailySummaries` 保存带单位的结构化汇总、覆盖范围、缺失项和参考/留出角色；Story 中的 `metrics` 保存单条事件数值。全局和单条均标记 synthetic。此批素材不会实现 baseline 算法；当前 Ask AI 仍只读取宠物基本信息与聊天，不自动读取这些历史记录。已有原型的手动编辑功能未提供全部测试指标的编辑入口。

## 安全导入

显式执行 `scripts/import-synthetic-pet.mjs <username> [photo-path]`。脚本从运行时输入读取密码，不保存凭据；运行前关闭终端回显，结束后恢复。需要本机 `.env.local` 的公开 Supabase 配置和已经初始化的账号工作区。

导入经正常账号登录和 RLS 完成，不使用管理员 Key。只追加这个固定 dataset ID 的宠物，并切换当前宠物选中项；重复执行不会覆盖或重复插入。写入检查 revision，冲突时停止，避免覆盖其他设备的新内容。脚本读回验证45条记录、7天汇总、原有宠物未改变以及私有头像字节一致。

数据库变更后，已打开 Pawsona 的设备需要先刷新，再编辑或切换宠物，避免旧页面尝试保存过期版本。

## App 内容语言

Fixture 中的宠物名称、性格、观察标题、正文、背景、作者标签和生活事件全部使用英文。本文档是团队内部说明，因此保留中文。数据库中已有的这批生成内容可用 `scripts/localize-synthetic-pet.mjs <username>` 按 ID 更新为英文，保留数值、时间和头像。
